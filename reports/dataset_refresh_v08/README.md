## 无上下文筛选和新题证据复核

采用 [MemAgent 的提示与采样参数](https://github.com/BytedTsinghua-SIA/MemAgent/blob/main/taskutils/memory_data/filter.py)，
不提供上下文，temperature=1.0、top_p=0.7、输出上限 512、并发 8。
沿用旧题集既定条件：四次有效 boxed 最终答案的官方归一化 EM 都为 0。
HTTP 错误、超时和无效输出不会视为答错；上游的全文包含检查仅作诊断。

最初尝试 4B/9B 各两次，4B 反复返回 503 或超时，因此本批在说明调整后使用
用户此前配置的 **Qwen/Qwen3.5-9B 四次独立回答**。
最终筛查 304 道 comparison、19 道 inference，分别有 42、17 道四次回答全错。
本批完成的筛选决策没有 INVALID；之前中断的 4B 尝试不参与最终入选。

从候选中审查全文后，选出 25/5。额外排除的情况包括：

- dev_10853、dev_9427：只有标题语言、风格或导演身份，没有明确电影来源国家。
- dev_3553：合拍片来源国家有交集但集合不同，same country 的含义可能不一致。
- dev_8305：祖父关系只存在于 gold 三元组，正文没有父亲的父亲关系。
- dev_9537、dev_8731：共有孩子不足以证明婚姻，配偶的孩子不足以区分亲生或继子。
- dev_401、dev_6027、dev_832：无上下文回答已有正确名称或其缩写，EM 失分可能来自片名/头衔口径，保守排除。
